# 数据备份恢复指南

## 备份包含

- 机构资料。
- 管理员和教师账号。
- 密码 hash。
- 使用统计元数据。
- 模型选择配置。

## 备份不包含

- API Key。
- `app.env`。
- 学生图片。
- 学生背景资料正文。
- AI 报告正文。

## 创建备份

管理员后台可点击“立即创建备份”。无法登录网页时，可双击 `备份数据库.bat`。

备份文件默认保存到：

```text
C:\ProgramData\XinlingHuajuan\backups\database
```

每个备份会生成 SQLite `.db` 文件和安全元数据 `.json`，包括版本、时间、大小和 SHA-256。

## 恢复

恢复会覆盖当前机构、账号和统计数据。管理员需要输入当前密码并二次确认“确认恢复”。系统会先创建恢复前备份，再校验备份完整性，失败时尝试回滚。

恢复成功后，所有 session 会失效，用户需要重新登录。
