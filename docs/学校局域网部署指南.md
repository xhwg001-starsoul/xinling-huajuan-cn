# 心灵画卷 · 学校局域网部署指南

适用于一所学校在一台长期稳定开机的 Windows 电脑上部署“心灵画卷 · 大陆版”，校内教师通过浏览器访问。

## 基本要求

- Windows 10/11 或 Windows Server。
- Node.js 20 或更高版本。
- 建议主机使用固定局域网 IP，或在路由器/DHCP 中为该电脑保留地址。
- Qwen-VL 和 DeepSeek 仍需要互联网访问模型供应商 API。
- 不要配置公网端口映射，不要把本系统直接暴露到互联网。

## 首次安装

1. 解压学校部署包到固定程序目录。
2. 双击 `首次安装与配置心灵画卷.bat`。
3. 按提示配置端口、数据目录、Qwen/DeepSeek/OpenAI 等环境变量。
4. 配置文件保存到 `C:\ProgramData\XinlingHuajuan\config\app.env`。
5. 启动后访问 `http://127.0.0.1:4185` 初始化管理员。

## 局域网访问

- 本机访问：`http://127.0.0.1:4185`
- 其他校内电脑访问：`http://主机局域网IP:4185`
- 如需开放 Windows 防火墙，双击 `配置局域网访问.bat`，该脚本只开放 Private 网络的当前 TCP 端口。

## 数据目录

school 模式默认数据目录：

```text
C:\ProgramData\XinlingHuajuan
```

子目录：

- `database`：SQLite 数据库。
- `config`：`app.env` 配置。
- `backups`：数据库备份。
- `logs`：运行日志。
- `runtime`：PID 等运行状态。
- `updates`：升级临时文件。

## 隐私提醒

系统不长期保存学生图片、学生背景资料正文或 AI 报告正文。生成报告期间，图片会发送给当前配置的视觉模型供应商，背景资料和视觉观察会发送给当前配置的文本模型供应商。不要输入学生真实姓名、身份证号、详细住址或联系方式。
