# 系统升级指南

学校端不依赖 GitHub、Git 或 `git pull` 升级。维护者生成本地 ZIP 更新包后，由学校管理员在本机安装。

## 创建发布包

维护者双击：

```text
创建学校部署包.bat
```

发布目录会生成：

- `xinling-huajuan-cn-v0.9.0.zip`
- `xinling-huajuan-cn-v0.9.0.sha256`
- `release-manifest.json`

发布包不包含 `.env.local`、`app.env`、数据库、备份、日志、runtime、updates、`.git` 或学生数据。

## 学校端升级

双击：

```text
升级心灵画卷.bat
```

v0.9 采用保守升级策略：脚本会校验 ZIP、创建升级前数据库备份和代码备份，并检查更新包不含配置或数据目录。正式替换代码建议在维护窗口人工完成。

不要使用 `git pull` 直接升级学校主机。
