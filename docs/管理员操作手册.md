# 管理员操作手册

管理员可以在教师工作台中完成以下操作：

- 创建教师账号。
- 启用或停用教师账号。
- 重置教师密码。
- 修改机构信息。
- 修改模型设置。
- 查看使用统计。
- 查看系统运行状态。
- 创建、下载、删除数据库备份。
- 从已有备份恢复数据库。

## 账号

教师不再被强制要求首次登录修改密码。管理员创建或重置密码后，应通过安全方式把用户名和密码交给教师。教师可登录后在工作台主动修改自己的密码。

## 模型设置

只有 admin 可以看到模型设置。普通 teacher 看不到模型供应商、模型名称和 API Key 配置状态。

API Key 只保存在服务器环境变量或 `C:\ProgramData\XinlingHuajuan\config\app.env`，不会保存到 SQLite。

## 系统状态

系统状态只显示安全摘要，例如版本、运行模式、数据库状态、最近备份和局域网地址，不显示 API Key、密码、token 或完整环境变量。
